# 4.2 캠페인 랭킹 Top3(Bar) 설계

## 배경

`docs/mobidays_fe_assignment_guide.md`의 `4.2 캠페인 랭킹 Top3`는 선택 과제이지만, 글로벌 필터 결과를 기준으로 캠페인 성과를 빠르게 비교하게 해 주는 보조 인사이트 위젯이다. 단순히 막대 3개를 그리는 수준이 아니라, 현재 필터 조건에 맞는 캠페인 중 어떤 것이 더 효율적인지를 즉시 보여주는 비교 도구로 봐야 한다.

현재 코드베이스에는 다음 기반이 이미 존재한다.

- 전역 필터 atom과 `useDashboardData(filter)` 기반 조회 흐름
- MSW 기반의 브라우저 메모리 데이터 소스
- `recharts` 기반 공용 차트 래퍼
- 캠페인별 집계 지표를 계산하는 데이터 변환 패턴

따라서 이번 기능은 새 API를 만들기보다, `campaigns`와 `dailyStats` 조회 결과를 캠페인 단위로 다시 집계한 뒤 메트릭 기준 상위 3개만 보여주는 방식이 가장 적합하다.

## 목표

- `ROAS / CTR / CPC` 3개 메트릭을 토글할 수 있는 막대 차트를 제공한다.
- 기본 선택 메트릭은 `ROAS`로 고정한다.
- 선택한 메트릭 기준 상위 3개 캠페인을 노출한다.
- `ROAS`와 `CTR`은 높은 값이 상위, `CPC`는 낮은 값이 상위가 되도록 정렬한다.
- 글로벌 필터 결과를 기준으로 다시 계산되도록 한다.
- 계산 불가 항목은 랭킹에서 제외하고, 화면은 안전하게 empty state 또는 축소된 목록으로 유지한다.

## 비목표

- 새로운 서버 API 추가
- 플랫폼별 성과 차트와의 상호작용 추가
- 랭킹 클릭 시 전역 필터를 바꾸는 동작 추가
- 순위 3개를 초과하는 목록 제공
- 서버 측 정렬/페이지네이션 API 추가

## 핵심 결정

### 1. 랭킹 기준은 현재 글로벌 필터 결과를 사용한다

Top3는 독립 데이터가 아니라 전역 필터로 이미 좁혀진 결과에 대해 계산한다.

- 입력 데이터는 `useDashboardData(filter)`가 반환한 현재 필터 결과를 사용한다.
- 필터가 바뀌면 랭킹도 즉시 다시 계산한다.
- 이 위젯은 글로벌 필터의 보조 표현이므로, 별도의 자체 필터 상태를 두지 않는다.

이 방식이면 다른 위젯과 같은 데이터 기준을 공유하게 되어 해석이 일관된다.

### 2. 메트릭 토글은 로컬 상태로 둔다

메트릭 선택은 전역 상태가 아니라 위젯 내부 상태로 관리한다.

- 허용 메트릭은 `ROAS / CTR / CPC` 3개다.
- 기본값은 `ROAS`다.
- 사용자가 토글을 바꾸면 즉시 재정렬하고 다시 렌더링한다.

메트릭은 전역 필터가 아니므로 전역 상태에 넣지 않는다.

### 3. 랭킹에서 계산 불가 항목은 제외한다

`N/A`는 단순 표시용 값이 아니라, 랭킹 계산에서 제외해야 하는 상태로 다룬다.

- `ROAS`, `CTR`, `CPC` 계산 결과가 유효하지 않으면 해당 캠페인은 랭킹 대상에서 제외한다.
- 분모가 0인 경우는 `N/A`로 표시하지만, 랭킹 순위 산정에는 포함하지 않는다.
- 유효한 캠페인 수가 3개 미만이면 존재하는 만큼만 표시한다.
- 유효한 캠페인이 하나도 없으면 empty state를 보여준다.

이 규칙은 "순위를 매길 수 없는 항목은 순위를 매기지 않는다"는 해석을 명확히 반영한다.

### 4. 동점은 기존 데이터 순서를 유지한다

정렬 시 값이 같으면 별도의 보조 정렬을 추가하지 않고 기존 데이터 순서를 유지한다.

- `ROAS`와 `CTR`은 내림차순 정렬
- `CPC`는 오름차순 정렬
- 값이 같은 경우는 입력 순서 그대로 유지

이 규칙은 캠페인 이름이 `null`인 경우에도 불필요한 보조 정렬을 피할 수 있게 해 준다.

## 책임 경계

- `entities` 레이어
  - 캠페인 단위 집계 로직
  - 메트릭 계산
  - 숫자 정규화와 null 안전 처리
  - 순위 후보 선별
- `widgets` 레이어
  - 메트릭 토글 UI
  - 상위 3개 바 차트 렌더링
  - empty state 및 loading state 표현
  - 차트 라벨과 툴팁 표현

차트 위젯은 계산 로직을 직접 품지 않고, 계산된 랭킹 결과만 소비해야 한다.

## 데이터 계약

### 입력

차트는 다음 의미를 가진 정규화된 데이터만 필요로 한다.

```ts
type RankMetricKey = "roas" | "ctr" | "cpc";

interface RankedCampaignPoint {
	id: string;
	name: string | null;
	value: number | null;
	displayValue: string;
	rank: number;
}
```

실제 구현에서 세부 필드는 달라질 수 있지만, 의미는 다음을 유지해야 한다.

- `id`: 캠페인 고유 식별자
- `name`: 캠페인 명칭, `null` 가능
- `value`: 정렬에 사용할 원시 값
- `displayValue`: 화면에 보여줄 포맷된 값
- `rank`: 1, 2, 3 순위

### 출력

차트는 아래 정보를 화면에 노출해야 한다.

- 메트릭 토글 상태
- 상위 3개 캠페인의 순위
- 캠페인명
- 선택 메트릭의 값
- 선택 메트릭의 상대적 크기

## 집계 규칙

### 캠페인 단위 집계

각 캠페인 row는 해당 캠페인 ID에 속한 `dailyStats`만 합산 대상으로 사용한다.

### ROAS

```ts
(총 conversionsValue / 총 cost) * 100
```

- `cost` 분모가 0이거나 유효하지 않으면 `N/A`
- `conversionsValue`가 모두 `null`이면 `N/A`

### CTR

```ts
(총 clicks / 총 impressions) * 100
```

- `impressions` 분모가 0이거나 유효하지 않으면 `N/A`

### CPC

```ts
총 cost / 총 clicks
```

- `clicks` 분모가 0이거나 유효하지 않으면 `N/A`

### null 및 비정상 값 처리

데이터 원본에는 예외 상황이 포함될 수 있으므로, 집계 단계에서 안전하게 처리한다.

- `null`은 합계에서 제외한다.
- 숫자가 아닌 값은 제외한다.
- 합계 결과가 없으면 `N/A`로 본다.
- 분모가 0이면 `N/A`로 본다.

이 규칙은 과제의 `division by zero`, `null safety`, `데이터 정규화` 요구사항을 랭킹 데이터 변환 단계에서 일관되게 해결하기 위한 것이다.

## 정렬 규칙

### 메트릭별 정렬 방향

- `ROAS`: 내림차순
- `CTR`: 내림차순
- `CPC`: 오름차순

### 동점 처리

- 값이 같으면 기존 데이터 순서를 유지한다.
- 추가 보조 정렬은 사용하지 않는다.

### 랭킹 산정

- 정렬 후 앞에서부터 최대 3개를 선택한다.
- `value === null`인 항목은 정렬 전 단계에서 제외한다.
- 결과적으로 계산 가능한 값만 상위 랭킹에 들어간다.

## 표기 규칙

표시 포맷은 `캠페인 현황 테이블`에서 사용하는 규칙과 통일한다.

- `ROAS`, `CTR`: 퍼센트 포맷을 사용한다.
- `CPC`: 원화 단위와 천 단위 구분 표기를 사용한다.
- 소수점 자릿수와 천 단위 구분 방식은 테이블과 동일하게 유지한다.

`N/A`는 값이 계산 불가능함을 의미하므로, 랭킹 목록에는 포함되지 않는다.

## 인터랙션 규칙

### 메트릭 토글

- 3개 토글 `ROAS / CTR / CPC`를 모두 렌더링한다.
- 기본 선택값은 `ROAS`다.
- 단일 선택만 허용한다.
- 선택 변경 시 즉시 재정렬된다.

### 글로벌 필터 동기화

- 글로벌 필터가 외부에서 바뀌면 차트 데이터도 즉시 다시 계산한다.
- 차트는 필터의 보조 상태가 아니라 필터 결과의 표현이므로, 별도 선택 상태를 저장하지 않는다.

## UI 요구

- 카드형 위젯으로 구성한다.
- 헤더에 제목과 간단한 설명을 둔다.
- 본문에는 랭킹 막대와 순위 라벨을 함께 배치한다.
- 각 항목에는 캠페인명과 선택 메트릭 값을 함께 표시한다.
- `N/A`는 랭킹 항목으로 보여주지 않는다.

권장 문구는 다음과 같다.

- 제목: `캠페인 랭킹`
- 설명: `현재 필터 기준 상위 캠페인을 확인합니다.`

## 접근성 기준

- 메트릭 토글은 버튼으로 제공하고 현재 선택 상태를 `aria-pressed`로 노출한다.
- 막대만으로 정보가 전달되지 않도록 텍스트 라벨을 함께 제공한다.
- 색상만으로 순위 또는 선택 상태를 구분하지 않고, 순위 숫자와 텍스트를 함께 제공한다.
- `N/A` 상태는 시각적 표시만으로 끝내지 않고 텍스트로도 전달한다.

## 예외 처리

- 필터 결과에 해당하는 데이터가 없으면 empty state를 보여준다.
- 계산 가능한 캠페인이 1개 또는 2개뿐이면 그 수만큼만 표시한다.
- 계산 가능한 캠페인이 0개면 empty state를 보여준다.
- 불완전한 데이터가 섞여 있어도 위젯 전체가 깨지지 않아야 한다.
- 잘못된 수치가 들어와도 차트는 렌더링을 중단하지 않고 안전하게 축소된 상태를 유지해야 한다.

## 테스트 기준

- 메트릭 토글 3개 `ROAS / CTR / CPC`가 모두 렌더링되는지 검증한다.
- 기본 선택 메트릭이 `ROAS`인지 검증한다.
- `ROAS`, `CTR`은 내림차순, `CPC`는 오름차순으로 정렬되는지 검증한다.
- 동점일 때 기존 데이터 순서가 유지되는지 검증한다.
- `N/A` 항목은 랭킹에서 제외되는지 검증한다.
- 필터 결과에 따라 랭킹이 다시 계산되는지 검증한다.
- 유효한 데이터가 3개 미만일 때 있는 만큼만 표시되는지 검증한다.
