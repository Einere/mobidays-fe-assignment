# Design Context

이 문서는 프로젝트 디자인 컨텍스트의 기준 문서다.
에이전트와 사람이 모두 이 문서를 우선 참조한다.

## Users

광고/캠페인 운영 담당자가 반복적으로 사용하는 운영 대시보드다. 사용자는 캠페인 상태, 집행 성과, 기간별 통계, 필터링 결과를 빠르게 확인하고 판단해야 한다. 사용 맥락은 업무 시간 중 빈도가 높고, 정확한 수치 판독과 빠른 조작이 중요하다.

## Brand Personality

- 신뢰감
- 정확함
- 정밀함

## Aesthetic Direction

- 네이비 기반의 차분한 운영툴 톤
- 높은 정보 밀도에서도 유지되는 판독성
- 과장된 장식보다 안정적인 위계와 통제감 우선

## Design Principles

1. 정보는 빠르게 읽혀야 한다.
2. 상태는 즉시 구분되어야 한다.
3. 밀도는 높되 답답하면 안 된다.
4. 장식보다 통제감을 우선한다.
5. 임의값보다 토큰 시스템을 우선한다.
6. 데이터 의미는 색상 규칙까지 포함해 일관돼야 한다.
7. focus, selected, hover, disabled 상태는 명시적 semantic token으로 정의한다.
8. table, metric, form, caption 텍스트 역할을 분리한다.
